# Astro
Astro è un framework moderno per la costruzione di siti web statici e dinamici. Permette di creare pagine web utilizzando componenti riutilizzabili e supporta l'integrazione con vari framework JavaScript come React, Vue e Svelte.
## Caratteristiche principali
- **Componenti Riutilizzabili**: Crea componenti modulari che possono essere riutilizzati in diverse parti del tuo sito.
- **Rendering Statico**: Genera siti statici ottimizzati per le prestazioni.
- **Integrazione con Framework**: Supporta l'integrazione con framework JavaScript popolari.
- **Ottimizzazione delle Prestazioni**: Carica solo il JavaScript necessario per ogni pagina.
## Installazione
Per iniziare con Astro, assicurati di avere Node.js installato sul tuo sistema. Poi, esegui i seguenti comandi:
```bash
npm create astro@latest
cd nome-del-tuo-progetto
npm install
```
